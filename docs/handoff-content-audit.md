## Required evidence when completing an item

For a gallery asset, supply the local filename, event ID, descriptive title, factual alt text,
caption that distinguishes what the image directly shows from interpretation, creator/credit,
original object or publication URL, reuse licence or written permission basis, and licence URL when
one exists. A generic search-result page or copied social-media image is not sufficient.
